# Paediatric IBD Cross-cohort Metagenomics

Reproducible code for cross-cohort paediatric IBD metagenomic analysis.
The `paediatric-ibd-metagenomics` repository is intended to support reproducible
analysis through sanitized scripts, configuration templates, environment
specifications, and documentation.

## Scope

- Server-side metagenomic preprocessing.
- Local R-based statistical analysis.
- Machine-learning and random-forest modelling.

## Planned repository structure

```text
scripts/
  server/
  local/
config/
environment/
docs/
```

See [Repository structure](docs/repository_structure.md) for directory purposes.
Empty directories are not tracked by Git and will appear in clones when files
are added.

## Data policy

This repository does not provide raw data, processed data, patient-level
metadata, intermediate files, model objects, figures, tables, or analysis
results. Personal identifiers, credentials, and private storage information
must not be included. Public dataset accession numbers may be documented.
Any specific public example requires explicit approval before inclusion.
